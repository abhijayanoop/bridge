Spec

Goal

Let an account owner set an invoice to repeat every week, month or year, so they stop rebuilding the same invoice by hand.

Scope

  • –{{s.text}}{{x.v}}
    •

Out of scope

Custom intervals such as every 3 weeks. Proration when a schedule changes mid-cycle (proposed as BRG-113).

Data model

recurring_schedules
  id                  uuid  pk
  invoice_template_id uuid  → invoices.id
  interval            enum  weekly | monthly | yearly
  anchor_date         date
  next_run_at         timestamptz
  paused_at           timestamptz  null
  timezone            text

Acceptance criteria

  1. A monthly schedule anchored on Jan 31 issues on Feb 28 (or 29), then Mar 31.
  2. Pausing stops runs. Resuming skips missed runs and issues the next one on time.
  3. Each run issues exactly one invoice, even if the job retries.
  4. Run times are stored in UTC and evaluated in the account's timezone.
